# Modern Dashboard UI

A modern SaaS-style dashboard built with React, TypeScript, and Tailwind CSS.

## Live Demo

https://modern-dashboard-ui.vercel.app

## Features

- Responsive dashboard layout
- Navbar and sidebar navigation
- Data cards
- Interactive charts
- Orders table
- Dark mode support
- Skeleton loading states
- Accessibility improvements

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Recharts
- Vite
